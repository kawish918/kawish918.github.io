01 / FLAGSHIP SYSTEM Final Year Project · Network Security & Agentic SOC

SentiNet — Autonomous AI Intrusion Detection & SOC Platform

A real-time IDS/IPS platform with a dual-model anomaly engine (Autoencoder + LSTM-AE) achieving F1=0.98 and FPR=5.2% on CIC-IDS-2023, a GATv2 Graph Neural Network for structural attack detection, an Elastic Weight Consolidation (EWC) continual learning pipeline that prevents catastrophic forgetting, a concept drift detector using Welford online statistics, and a ReACT SOC agent on Llama-3.1-8B that queries live threat intel APIs before reasoning.

Detection: Autoencoder (12.8K params) + LSTM-AE (135K params) weighted voting + GATv2 GNN (ONNX, 40-feature edges)
Continual Learning: EWC with diagonal Fisher Information, auto-escalating λ (0→50), replay buffer stability testing
Concept Drift: Welford online statistics + 3σ z-score monitoring on reconstruction errors, benign-only filtering
SOC Agent: Llama-3.1-8B ReACT loop with MCP tool-calling (AbuseIPDB + VirusTotal) — zero hallucinated scores
Python PyTorch FastAPI React PySide6 PostgreSQL ONNX Runtime WinDivert

Architecture

Three-tier: Windows PySide6 endpoint agent (WinDivert packet capture, dual-model inline inference) → FastAPI central server (PostgreSQL, GATv2 GNN, enrichment) → React/TypeScript SOC dashboard with WebSocket live feed and 8-tab operational interface.

Detection

Dual-model weighted voting: Standard Autoencoder (per-flow MSE, 98th-percentile threshold) + LSTM-AE (10-flow sliding windows per source IP, autoregressive decoder). Three-tier verdicts: CRITICAL (both fire), LATERAL/STEALTHY (sequence-only), BURST/POLICY (flow-only). Server-side GATv2 GNN detects DDoS, BruteForce, Bot C2, and Infiltration across the full network topology.

EWC

Elastic Weight Consolidation (Kirkpatrick et al., 2017): estimates diagonal Fisher Information from 2,048 benign samples, adds F_i·(θ_i − θ*_i)² penalty during fine-tuning. Lambda auto-escalates: λ=0 on first CL cycle (fully adapt from CIC-23 pre-training), λ=50 on subsequent cycles (protect real-traffic weights). Cycle count persisted in cl_state.json.

Drift

ConceptDriftDetector monitors benign-only reconstruction errors using Welford online mean/variance (O(1) memory). Fires when z-score of the 500-sample recent window exceeds 3σ from the global mean. Attack flows are blocked and never reach the drift detector — preventing false drift from ongoing attacks. Rate-limited to 1 alert per 5 minutes.

Stability

ReplayBuffer (200 samples, persistent .npy) stores pre-CL anomalous flows and tests the new model against them post-training. High replay MSE = stability preserved; falling MSE = catastrophic forgetting detected. Overfitting guard: auto-rollback if val/train loss ratio exceeds 2.0. Threshold floor: clamped at 50% of old threshold.

SOC Agent

ReACT loop (max 5 iterations) on Llama-3.1-8B-Instruct. MCP tools pre-fetch real AbuseIPDB/VirusTotal data before LLM inference — the model reasons over verified threat intel, never fabricates reputation scores. Triages as CRITICAL / SUSPICIOUS / FALSE_POSITIVE / BEACONING with actionable recommendations.

Security

SHA-256 model integrity verification before loading (prevents pickle deserialization attacks). Threat-intel poisoning guard validates captured IPs against AbuseIPDB/VirusTotal before CL — aborts if validation fails. Server-pushed zero-trust config (agents cannot self-whitelist).

Engineering Philosophy

From problem to usable system.

A model is only as valuable as the reliability of the software pipeline surrounding it.

STEP 01

Frame the operational problem

Identify the end user, latency/privacy constraints, data reality, and the exact decision the system must support.

STEP 02

Select the right model stack

Match classical ML, deep learning, or local/hosted LLMs to the task and benchmark against clear baselines.

STEP 03

Orchestrate the full workflow

Connect inference, deterministic tools, FastAPI services, databases, and interfaces into one cohesive product.

STEP 04

Verify & safeguard outputs

Build explicit verification steps, inspect failure modes, and keep humans in control of high-stakes actions.
